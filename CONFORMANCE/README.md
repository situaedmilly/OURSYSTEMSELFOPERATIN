# Conformance fixtures

The files under fixtures/ are structural test inputs only. Their syntactically valid SHA-256 values are sentinel values unless a fixture explicitly identifies a recontactable evidence source and a matching digest. They are not live host measurements, model inference receipts, authority grants, admission decisions, execution receipts, or effect witnesses.

The session graph tests validate the stated invariants for the tested inputs. Passing tests does not certify a platform, constitutional ratification, production launch, or any untested adapter.
